🐜 琉璃蟻偵測演算法 · 敏感度測試台

保留學生原版演算法（暗像素比例 + 全畫面移動量），把常數開放調整，用上傳的照片做敏感度分析。所有運算都在你的瀏覽器裡完成，照片不會上傳到任何伺服器。

① 上傳影像

把圖片拖到這裡。多張圖會依檔名排序，當成連續畫面：每張的「移動量」是跟前一張比較（學生程式每 2.5 秒比一次）。

要測移動量，請上傳同一位置、同一解析度連拍的照片（例如在 ESP32 網頁開 http://192.168.4.1/capture 每隔幾秒存一張）。尺寸不同的兩張圖，學生程式會把移動量算成 0。

② 參數（預設值 = 學生原版）

調整後，上方表格與下方預覽會立即重算。
判斷規則（學生原版邏輯） 
gray  = wR·R + wG·G + wB·B
ratio = (gray < 暗像素閾值 的像素數) / 總像素數
avgDiff = 平均 |本張灰階 − 前一張灰階|

if (ratio > 比例下限 && ratio < 比例上限)
    avgDiff > 移動量閾值 ? 🐜 活動中 : ☠️ 群聚無位移
else
    ratio ≥ 比例上限 ? ⚠️ 大面積陰影/雜物 : ✅ 無琉璃蟻

說明

  • 演算法程式在 js/algorithm.js；學生原版逐字保留在 original/student_algorithm.js，並有測試確認預設參數下兩者結果一致。
  • 學生程式在 ESP32 網頁上即時分析串流。這個頁面放在 GitHub Pages（HTTPS），瀏覽器會擋下對 http://192.168.4.1 的混合內容，所以這裡改用上傳照片的方式測試。
  • 學生的紅框／紫框固定畫在畫面中央 40%，不代表螞蟻位置；預覽中保留它只是為了對照原版畫面。
  • ESP32 送出的是 JPEG，壓縮雜訊本身就會讓相鄰兩張的移動量大於 0。用手機照片測時，記得選接近 ESP32 的解析度。
